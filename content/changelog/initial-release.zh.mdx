我们很高兴宣布 ShipGo 首次发布！

## 新功能

- 基于 TanStack Start、Nitro 与 React 19 的全栈应用基座
- 基于 Better Auth 的完整认证体系，支持账密、社交登录及 `sgk_` API Key 管理
- 支持 Stripe 与 Creem 的订阅、终身买断及幂等积分账本系统
- 基于 Fumadocs MDX 与 Intlayer 的中英文双语文档与博客（`en` / `zh`）
- 生产级 Docker 部署、PostgreSQL 兼容检查与健康探针
