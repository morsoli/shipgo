Microsoft Clarity 提供免费会话录制、热图和用户交互洞察。

## 配置

1. 在 [Microsoft Clarity](https://clarity.microsoft.com/) 创建项目。
2. 复制 **Project ID**。
3. 添加到 `.env.local`：

```dotenv
VITE_CLARITY_PROJECT_ID=your-project-id
```

4. 重启应用。

## 跟踪内容

- 用户交互的会话录制。
- 点击与滚动热图。
- 愤怒点击和无效点击等挫败感指标。

## 隐私注意

会话录制可能捕获敏感用户输入。请在 Clarity 设置中屏蔽敏感字段，并在启用
录制前检查隐私政策。
