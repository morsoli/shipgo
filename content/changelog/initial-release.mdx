We're excited to announce the initial release of ShipGo!

## What's New

- TanStack Start and Nitro full-stack foundation with React 19
- Better Auth authentication with credentials, social login, and `sgk_` API keys
- Stripe and Creem payments with subscriptions, lifetime plans, and an idempotent credit ledger
- Bilingual documentation and blog powered by Fumadocs MDX and Intlayer (`en` / `zh`)
- Production Docker deployment with PostgreSQL compatibility checks and health probes
