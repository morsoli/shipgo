ShipGo 支持多种分析与跟踪 Provider。每种都只在配置了公开标识后才加载，因此缺少
可选集成不会阻止应用启动。

## 可用 Provider

| Provider | 类型 | 环境变量 |
| --- | --- | --- |
| Google Analytics | 流量分析 | `VITE_GA_MEASUREMENT_ID` |
| Umami | 隐私友好分析 | `VITE_UMAMI_WEBSITE_ID`、`VITE_UMAMI_SCRIPT_URL` |
| Plausible | 轻量分析 | `VITE_PLAUSIBLE_DOMAIN` |
| OpenPanel | 产品分析 | `VITE_OPENPANEL_CLIENT_ID` |
| Microsoft Clarity | 会话录制 | `VITE_CLARITY_PROJECT_ID` |
| Ahrefs | SEO 跟踪 | `VITE_AHREFS_SCRIPT_URL` |
| Datafast | 性能分析 | `VITE_DATAFAST_SCRIPT_URL` |
| Seline | 转化分析 | `VITE_SELINE_SCRIPT_URL` |

只有 `VITE_` 前缀变量会暴露给浏览器。如果需要分析 API 的服务端 API Key，
必须仅保留在服务端。

## 配置原则

1. 在选择的 Provider 创建账号。
2. 获取公开站点 ID 或跟踪代码。
3. 将对应 `VITE_` 变量添加到 `.env.local`。
4. 重启应用。
5. 在浏览器开发者工具的网络面板中验证跟踪脚本是否加载。

## 转化跟踪

转化跟踪将用户行为（注册、购买、功能使用）与营销活动关联。详见
[转化跟踪](/zh/docs/analytics/conversion-tracking)。

## 隐私与同意

启用分析前，请确认产品运营地区的用户同意与隐私义务。部分 Provider 自动处理
同意；其他则需要显式 opt-in 集成。
