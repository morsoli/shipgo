Microsoft Clarity provides session recordings, heatmaps, and user interaction
insights at no cost.

## Configuration

1. Create a project in [Microsoft Clarity](https://clarity.microsoft.com/).
2. Copy the **Project ID**.
3. Add it to `.env.local`:

```dotenv
VITE_CLARITY_PROJECT_ID=your-project-id
```

4. Restart the application.

## What is tracked

- Session recordings of user interactions.
- Click and scroll heatmaps.
- Frustration indicators such as rage clicks and dead clicks.

## Privacy notes

Session recordings may capture sensitive user input. Mask sensitive fields in
Clarity settings and review your privacy policy before enabling recordings.
